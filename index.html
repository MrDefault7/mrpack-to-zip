    01What it does
    
			
    
				
    A modpack archive, without the launcher
    
				
    
					An MRPack is the Modrinth modpack format. It is a ZIP archive that
					contains a modrinth.index.json manifest, plus optional
					overrides, client-overrides, and
					server-overrides folders. The manifest lists the files the pack needs
					and where to download each one.
				
    
				
    
					Renaming an .mrpack to .zip is not a conversion. You get an
					archive of instructions, not a usable pack. This tool reads the manifest, copies the
					override files, downloads the files the manifest points to, and assembles everything
					into a new ZIP with a sensible filename.
				
    
				
    
					The result is a client-oriented archive: overrides and
					client-overrides are included, while server-overrides are
					not. Download sources and browser restrictions still apply, so some individual files
					may be left out. When that happens, the result screen tells you exactly which ones.
				
    
			
    
		
    
	
    

	
    
		
    
			
    
				
    02 How to convert
    
				
    How it works
    
				
    Entirely client-side. Your file never leaves your device.
    
			
    
			
      
				
    1. 
					
						
					
					
      Parse manifest
      
					The converter reads modrinth.index.json inside your .mrpack, right in the browser, to find the mod list and overrides.
				
      2. 
				
    2. 
					
						
					
					
      Fetch resources
      
					Your browser downloads the listed files directly from their original hosts, such as Modrinth's CDN.
				
      3. 
				
    3. 
					
						
					
					
      Bundle ZIP
      
					Mods, configs and overrides are organised into a standard ZIP layout that archive tools and launchers understand.
				
      4. 
				
    4. 
					
						
					
					
      Instant download
      
					The final ZIP is generated locally and saved by your browser. Nothing is ever uploaded to a server.
				
      5. 
			
    
		
    
	
    

	
    
		
    
			
    03Privacy & processing
    
			
    
				
    Where your file actually goes
    
				
    
					The .mrpack you select is read with JavaScript in your browser. It is not
					uploaded to this website, and there is no server-side upload endpoint to send it to.
					The generated ZIP is assembled in memory and saved directly by your browser.
				
    
				
    
					Conversion is not fully offline. The manifest lists download URLs, and the converter
					requests those files from the external hosts that serve them. Those hosts receive
					normal connection information, including your IP address, and apply their own privacy
					policies. Requests to hosts that do not allow cross-origin browser access will fail.
				
    
				
    
					No accounts, no analytics, no cookies. This page does not include
					analytics scripts, advertising, or tracking pixels. The only thing it saves in your
					browser is your colour theme preference, which never leaves your device.
				
    
				
    
					The full detail is in the privacy policy, including what
					happens to files held in memory and which third-party hosts are involved.
				
    
			
    
		
    
	
    

	
    
		
    
			
    04Questions
    
			
    
				
    Frequently asked
    
				
    
					
    
						What is an MRPack file?
						
    
							
    MRPack is Modrinth's modpack format. It is a ZIP archive containing a
							modrinth.index.json manifest, optional override folders, and
							optionally some bundled files. Launchers use the manifest to fetch the rest of
							the pack.
    
						
    
					
    
					
    
						How do I convert MRPack to ZIP?
						
    
							
    Select your .mrpack file above, press Convert to ZIP, and
							wait for the downloads and archive build to finish. The finished ZIP is saved to
							your downloads folder. Nothing needs to be installed.
    
						
    
					
    
					
    
						Do I need to install any software?
						
    
							
    No. The converter runs entirely in a modern browser. There is no desktop app,
							extension, command line tool, or account.
    
						
    
					
    
					
    
						Does the website upload my MRPack?
						
    
							
    No. The selected file is read in your browser and never sent to this site's
							server. The converter does make outbound requests for the files listed in the
							manifest, because those files have to come from somewhere. Those requests go to
							external download hosts, not to us.
    
						
    
					
    
					
    
						Why can some mods fail to download?
						
    
							
    A manifest entry can point to a link that has expired, been removed, or is
							temporarily unavailable. It can also point to a host that does not permit
							cross-origin requests from a browser. In those cases the file cannot be read
							into the ZIP, and the result screen lists it as missing.
    
						
    
					
    
					
    
						Why do some download links open in a new tab?
						
    
							
    Files hosted on GitHub are handled that way. GitHub's release download
							endpoints do not allow browser scripts to read their responses, so the converter
							cannot put them inside the archive. Instead it opens the link so you can download
							the file yourself, then move it into the matching folder in the ZIP. GitHub-hosted
							entries are reported after conversion.
    
						
    
					
    
					
    
						Can I use the converter on mobile?
						
    
							
    Yes. The interface works on current mobile browsers and adapts down to small
							phones. Large packs consume a lot of memory, though, and mobile browsers are
							quicker to run out of it. If a large pack fails on a phone, try a desktop
							browser.
    
						
    
					
    
					
    
						Is the converter free?
						
    
							
    Yes. There is no charge, no account, and no paid tier. The conversion engine
							is open source and the interface is a separate design by MrDefault.
