1. The service

MRPack to ZIP is a free tool that reads a Modrinth .mrpack file in your browser and assembles a plain ZIP archive from its manifest and override folders. It is a client-side utility: the selected file is not uploaded to this site.

The service is offered for convenience. It is not a launcher, an installer, or an official Modrinth product, and it does not modify or endorse the contents of any modpack.

4. Downloads, third parties and completeness

The converter downloads files listed in a pack's manifest from the external hosts named in that manifest. Those hosts are independent of this site. Links can expire, files can be removed, hosts can rate-limit requests, and cross-origin browser restrictions can prevent a file from being read at all.

As a result, no guarantee is made that every mod, resource pack, or other file will be included. In particular, GitHub-hosted entries are opened in a new tab instead of being added to the archive. The result screen reports which files were skipped, but you are responsible for checking that your final pack is complete before using it.

Large packs can exceed the memory available to a browser tab. If that happens, the conversion fails rather than producing a partial archive silently.
