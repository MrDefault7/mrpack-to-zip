Privacy Policy

This page explains what happens to a file you select in the converter, what data leaves your browser, and what this website does not collect.

Effective 18 October 2026

The short version

The .mrpack file you select is read in your browser and is not uploaded to this website. There are no accounts, no analytics scripts, no advertising, and no cookies. The only thing kept in your browser is your colour theme choice. During conversion, the converter downloads the files listed in your pack's manifest from the external hosts that serve them, and those hosts see your network request as they would for any download.

1. Who operates this site

This website is an independent project. The interface is designed by MrDefault, and the conversion engine is based on the open-source Fabulously Optimized MRPack-to-ZIP project. No company, account system, or registered legal entity is presented on this site.

2. Your selected file

When you choose a file, your browser gives the page's JavaScript access to its contents. The file is opened with the JSZip library in memory to read modrinth.index.json and any override folders. It is not transmitted to, or stored on, a server belonging to this site. There is no upload endpoint in the application.

The generated ZIP is also assembled in memory. Your browser then saves it to your device's downloads folder using its normal download mechanism.

3. Files downloaded from other hosts

An MRPack manifest lists download URLs for the files that make up the pack. The converter requests those URLs directly from your browser. This means:

  • The request goes to the host named in the manifest, not through this site.
  • That host receives standard technical information, such as your IP address, your browser's user agent, and the requested file.
  • Those hosts process that information under their own privacy policies. This site does not control them.
  • If a host blocks cross-origin browser requests, the file cannot be read into the ZIP and is reported as missing.

Most Modrinth packs reference cdn.modrinth.com and, for some entries, github.com. You can read the relevant policies here:

  • Modrinth privacy policy
  • GitHub privacy statement

A pack creator can reference any host in a manifest. If a different host appears in your pack, that host's own policy applies to its request.

4. What this site does not collect

The application itself does not collect or transmit: your name, email address, account details, the contents of your selected file, uploaded files, analytics events, session recordings, advertising identifiers, or form submissions. It sets no cookies and writes nothing to sessionStorage or IndexedDB. The single value it does keep locally is described in the next paragraph.

The one exception is your colour theme choice. If you switch between light and dark, that choice is saved in your browser's localStorage under a single key so the next visit looks the same. It contains only the words "light" or "dark", it is never transmitted, and clearing site data removes it. Following your system setting is the default; the converter works with JavaScript storage disabled, it simply forgets the choice.

Because the site is served as static files, the web host that delivers those files may keep standard access logs. Those logs typically include an IP address, user agent, requested path, and timestamp, and are used for delivery, security, and abuse prevention. Such logging is controlled by the hosting provider, not by this application. The same applies to any CDN used to deliver the site's files.

5. Retention and memory

While a conversion is in progress, the selected archive, the downloaded files, and the generated ZIP are held in your browser's memory. Closing or refreshing the page, or selecting another file, discards them. Anything already saved to your downloads folder remains on your device until you delete it.

This site has no database and no server-side storage for your files, so there is no server-side copy to delete.

6. Third-party code and links

The converter loads its own files only: three open-source libraries (JSZip, FileSaver.js, and the conversion engine), the interface scripts, and a small script that remembers the colour theme. No third-party scripts, fonts, or embedded widgets are loaded at runtime, so no other service learns that you visited this page. Links to Modrinth, GitHub, and the upstream project leave this site and are governed by those sites' policies.

7. Children and legal basis

The site is a general-purpose file utility and does not knowingly collect personal information from anyone, including children. Because no personal data is collected by the application, there is no profile built and nothing to sell or share.

8. Your choices

You can use the site without providing any personal information. If you do not want your IP address disclosed to a download host, do not start a conversion, or use network-level privacy tools. Blocking third-party requests may cause manifest files to be skipped; the result screen reports what was not included.

9. Changes to this policy

If the application's data handling changes, this page will be updated with a new effective date. Any future analytics or account feature would have to be described here before it is enabled.

10. Contact

For questions about this policy or the converter's behaviour, open an issue on the project's issue tracker. No dedicated email address is published for this deployment. Please do not include sensitive personal information in a public issue.
